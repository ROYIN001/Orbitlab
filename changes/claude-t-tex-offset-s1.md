## CHANGELOG

- Build (T-offset step 1, D-38 identical-output offset): the three progressive Earth textures (`earth_atmos_4096`, `earth_clouds_4096`, `earth_lights_4096`) are re-encoded losslessly from their own DCT coefficients, using MozJPEG's Huffman and scan optimisation and keeping all metadata; they stay progressive and every decoded pixel is identical (jpeg-js and Chromium, checked by `tests/verification/jpeg-pixels.test.mjs` and `scripts/jpeg-identical.mjs`); precache code is 35.1 kB smaller; no dependency added.

## PROGRESS
