## CHANGELOG

- Offline app (EQ-1, M-PLATFORM-021, P1 perf): a first visit no longer downloads the app's files a second time. This saves about 9.5 MB per first visit; only the 15 kB page itself is still fetched twice. When the offline install starts, it takes the files the page has just loaded from the browser's own cache, after checking each one against the build's fingerprint for that file. A file that does not match is downloaded fresh and checked the same way. Files are handled six at a time instead of all at once. The installed files are unchanged.
