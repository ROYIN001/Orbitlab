It was the recording's own object, so a panel that wrote into it would have changed the recording. Nothing does that today, and now a seek's frame cannot. What a seek shows is unchanged to the bit. PR #188 has carried the same copy since its f746b8c; on top of #188's head (f552f2d) this PR adds the lesson's flight as a test and no byte to any chunk.
