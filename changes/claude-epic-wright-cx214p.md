## CHANGELOG

- Replay (bug fix): in a six-DOF flight with control-system failures set (the lesson "A failed rate gyro" in pack 24.05.06, or Engineer mode's "Control-system failures"), a frame handed out by a seek or a replay now has its own copy of the failures and the FDIR's state. It was the recording's own object, so a panel that wrote into it would have changed the recording. Nothing does that today, and now a seek's frame cannot. What a seek shows is unchanged to the bit; the two chunks that carry the code are 88–90 B larger.
