## CHANGELOG

- Replay (bug fix): a frame handed out by a seek or a replay is now its own copy all the way down, as `cloneFrame` promised. The parts a rocket dropped on the way up, Apollo's state (its Moon figures, plan and the CSM, ascent stage and service module beside it) and the place a returning booster is flown to were still the recording's own objects, so a panel that wrote into what it was given would have changed the recording, and for the booster's landing place, the live simulation's guidance. Nothing does that today, and now a seek's frame cannot (a live frame still shares the landing place with the simulation; see the report). What a seek shows is unchanged to the bit on all 20 watch missions; the two chunks that carry the code are 161–163 B smaller each.
