ความเป็นส่วนตัว: Orbitlab เก็บอะไรไว้ในเครื่องนี้

  • ไม่มีบัญชีผู้ใช้ ไม่มีโฆษณา ไม่ใช้คุกกี้ ไม่มี analytics หรือ telemetry
  • ชื่อ งาน และคะแนนอยู่ในเบราว์เซอร์ของเครื่องนี้เท่านั้น ผู้พัฒนาไม่ได้รับ เพราะไม่มีเซิร์ฟเวอร์รับข้อมูล
  • ข้อมูลออกจากเครื่องเมื่อคุณส่งออกไฟล์หรือคัดลอกลิงก์แล้วส่งต่อเองเท่านั้น
  • โปรไฟล์ไม่มีรหัสผ่าน ทุกคนที่ใช้เบราว์เซอร์เดียวกันบนเครื่องนี้เปิด ส่งออก หรือลบได้ทุกโปรไฟล์

ลบทุกอย่าง: ล้างข้อมูลเว็บไซต์ของ Orbitlab ในการตั้งค่าเบราว์เซอร์ หน้าต่างส่วนตัวลบทุกอย่างเมื่อปิด Safari บน iPhone/iPad อาจลบข้อมูลของเว็บที่ไม่ได้เปิดราว 7 วันถ้าไม่ได้เพิ่มไว้ที่หน้าจอโฮม จึงควรส่งออกไฟล์สำรองเป็นระยะ

เครื่องที่ใช้ร่วมกันในโรงเรียน: ให้แต่ละคนใช้บัญชีหรือโปรไฟล์เบราว์เซอร์ของตัวเอง หรือส่งออกไฟล์สำรองแล้วลบโปรไฟล์เมื่อเลิกใช้ ใช้ชื่อเล่นหรือรหัสแทนชื่อจริงได้

ผู้ช่วย AI ที่คุณติดตั้งในเบราว์เซอร์ (ถ้ามี) ใช้เครื่องมือ WebMCP ของ Orbitlab อ่านความคืบหน้าและผลแบบทดสอบของโปรไฟล์ที่เปิดอยู่ได้ และส่งต่อตามนโยบายของผู้ให้บริการผู้ช่วยนั้น

อินเทอร์เน็ต

ตัวแอปโหลดจาก GitHub Pages ซึ่งอาจบันทึกที่อยู่ IP ชนิดเบราว์เซอร์ และเวลาตามนโยบายของ GitHub โหมดออนไลน์ (ปิดอยู่โดยค่าเริ่มต้น) ขอข้อมูลจาก services.swpc.noaa.gov celestrak.org และฟอนต์จาก fonts.googleapis.com fonts.gstatic.com คำขอไม่มีชื่อ งาน หรือคะแนน แต่เซิร์ฟเวอร์เห็นที่อยู่ IP ลิงก์ภารกิจหรือบทเรียนที่คัดลอกมีค่าตั้งอยู่ในลิงก์ ไม่มีชื่อหรือคะแนน

ไฟล์ที่ส่งออก

ไฟล์ที่ดาวน์โหลดอยู่ในโฟลเดอร์ดาวน์โหลด นอกการควบคุมของ Orbitlab ไฟล์สำรองและไฟล์ผลการเรียนมีชื่อและคะแนน การลบโปรไฟล์ไม่ลบไฟล์เหล่านี้ ไฟล์ที่ส่งให้ครูหรือโรงเรียนอยู่ในความดูแลของผู้รับ

คะแนน รายงานปัญหา และสิทธิของคุณ

คะแนนในแอปใช้เพื่อพัฒนาการเรียนรู้ (formative) เป็นค่าเริ่มต้น ไม่ใช่คะแนนสอบทางการ แอปไม่ส่งรายงานปัญหาเองและไม่เก็บข้อมูลอัตโนมัติ แจ้งปัญหาเองได้ทาง GitHub หรืออีเมล โดยไม่ต้องใส่ชื่อจริงของผู้เรียน

พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 (PDPA) ให้สิทธิเข้าถึง แก้ไข และลบข้อมูลของตน ข้อมูลอยู่ในเครื่องของคุณ จึงทำได้เองทันที: ส่งออกไฟล์สำรอง เปลี่ยนชื่อ ลบโปรไฟล์ หรือรีเซ็ตประวัติ ผู้เรียนอายุต่ำกว่า 20 ปีควรใช้งานโดยผู้ปกครองหรือครูรับทราบ การศึกษาผู้ใช้ของโครงการมีใบยินยอมแยกต่างหาก

Privacy: what Orbitlab keeps on this device

  • No accounts, no ads, no cookies, no analytics or telemetry.
  • Names, work and scores stay in this device's browser. The developer does not receive them: there is no server that receives data.
  • Data leaves the device only when you export a file or copy a link and pass it on yourself.
  • Profiles have no password: anyone using the same browser on this device can open, export or delete every profile.

Delete everything: clear Orbitlab's site data in the browser settings. A private window deletes everything when closed. Safari on iPhone/iPad may delete data of a site not opened for about 7 days unless added to the Home Screen, so export a backup now and then.

Shared school computers: give each learner their own account or browser profile, or export a backup and delete the profile when done. A nickname or code can replace a real name.

An AI assistant you installed in the browser (if any) can read the open profile's progress and test results through Orbitlab's WebMCP tools, and passes them on under its provider's policy.

Internet

The app is loaded from GitHub Pages, which may log IP address, browser type and time under GitHub's policy. Online mode (off by default) fetches from services.swpc.noaa.gov, celestrak.org and fonts from fonts.googleapis.com fonts.gstatic.com. Requests carry no names, work or scores, but the servers see your IP address. A copied mission or lesson link carries its settings, no names or scores.

Exported files

Downloaded files sit in the downloads folder, outside Orbitlab's control. Backups and results files contain the name and scores. Deleting a profile does not delete them. A file given to a teacher or school is in the receiver's care.

Scores, problem reports and your rights

Scores in the app are formative by default: for learning, not official grades. The app never sends a problem report by itself and collects nothing automatically. Report problems yourself on GitHub or by email, without learners' real names.

Thailand's Personal Data Protection Act B.E. 2562 (2019, PDPA) gives the right to access, correct and erase your data. The data is on your device, so you do it yourself at once: export a backup, rename, delete a profile or reset records. Learners under 20 should use the app with a parent's or teacher's knowledge. The project's user studies have their own consent form.

Конфиденциальность: что Orbitlab хранит на этом устройстве

  • Нет учётных записей, рекламы, cookie, аналитики и телеметрии.
  • Имена, работы и баллы остаются в браузере этого устройства. Разработчик их не получает: сервера, принимающего данные, нет.
  • Данные покидают устройство, только когда вы сами экспортируете файл или копируете ссылку и передаёте её.
  • У профилей нет пароля: любой, кто пользуется тем же браузером на этом устройстве, может открыть, экспортировать или удалить любой профиль.

Интернет

Приложение загружается с GitHub Pages, где по правилам GitHub могут записываться IP-адрес, тип браузера и время. Онлайн-режим (по умолчанию выключен) запрашивает данные у services.swpc.noaa.gov, celestrak.org и шрифты у fonts.googleapis.com fonts.gstatic.com. В запросах нет имён, работ и баллов, но серверы видят ваш IP-адрес. Скопированная ссылка на миссию или урок содержит их настройки, без имён и баллов.

Экспортируемые файлы

Загруженные файлы лежат в папке загрузок, вне контроля Orbitlab. Копии и файлы результатов содержат имя и баллы. Удаление профиля их не удаляет. За файл, переданный учителю или школе, отвечает получатель.

Баллы, сообщения о проблемах и ваши права

Баллы в приложении по умолчанию формирующие: для обучения, а не официальная оценка. Приложение само не отправляет сообщения о проблемах и ничего не собирает автоматически. Сообщайте о проблемах сами через GitHub или по электронной почте, без настоящих имён учащихся.

Закон Таиланда о защите персональных данных B.E. 2562 (2019, PDPA) даёт право на доступ к своим данным, их исправление и удаление. Данные на вашем устройстве, поэтому вы делаете это сами и сразу: экспорт копии, переименование, удаление профиля, сброс записей. Учащимся младше 20 лет следует пользоваться приложением с ведома родителей или учителя. У исследований с пользователями есть отдельная форма согласия.
