# ตรวจ draft ตัวเลขหลังจบบทเรียนการบิน 1.1

ตรวจผ่าน UI จริงในโปรไฟล์ QA บน Windows ที่พอร์ต 4183 เมื่อ 29 กันยายน 2026 ประมาณ 22:24–22:27 UTC เปิดบท 1.1 กดปล่อย Falcon 9 และเร่งจนการบินเข้าสู่วงโคจรเป้าหมาย 500 กม. แล้วทดสอบช่องคำตอบที่ยังไม่ได้กดตรวจ ดู [ผลและค่าที่สังเกตจริง](browser-flight-draft-final-validation.json)

- ตัวเลขดิบ ` 94.70 ` รวมช่องว่างและ `7.617` คงเดิมหลังเปิดคำใบ้ และหลังเปลี่ยนไทย → รัสเซีย → อังกฤษ
- ข้อความตัวเลขที่ยังพิมพ์ไม่ครบ `1e` ไม่ถูกแปลงหรือทิ้งเมื่อเปิดคำใบ้ถัดไป
- การพิมพ์ `0` ต่อจาก `94.7` ได้ `94.70` โดยโฟกัสอยู่ที่ INPUT และเคอร์เซอร์อยู่ตำแหน่ง 5
- เมื่อกลับภาษาไทยและโฟกัสตัวเลือกภาษา ป้ายคำตอบเป็นไทยและค่าทั้งสองยังอยู่ ไม่ได้กดตรวจคำตอบหรือเปิดเฉลยในลำดับนี้

ข้อสังเกตของเครื่องมือ: `selectOption` ไม่ย้ายโฟกัสจากช่องคำตอบเหมือนการคลิกเลือกภาษาจริง ขณะช่องคำตอบยังมีโฟกัส ตัวแสดงบทเรียนตั้งใจรอเพื่อรักษาการพิมพ์ หลังคลิกตัวเลือกภาษาแล้วกด Escape ป้ายไทยแสดงตามปกติ ไม่จัดเป็นบั๊กผลิตภัณฑ์

หน้าเดิมใช้ build ที่ cache ไว้จาก `c146a699` โดย DOM ระบุ `index-BQdJTgBe.js` ตรง [build log](editorial-audit/final-build.log) ไม่อ้างว่าหน้านี้รัน build ของ `76534dc1` ส่วนต่างรุ่นสุดท้ายมีเพียงสถานะส่งออกสามภาษา ไม่เปลี่ยน logic บทเรียน ผลนี้ปิดเส้นทางตัวอย่าง flight numeric/hint/language/focus ที่ตรวจจริงหนึ่งบท ไม่ใช่ทุกบท ทุกลำดับโฟกัส การเก็บ draft ข้าม reload หรือ storage refusal
