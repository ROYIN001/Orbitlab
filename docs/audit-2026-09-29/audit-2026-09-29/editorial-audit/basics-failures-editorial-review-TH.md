# ตรวจบรรณาธิการธนาคาร Basics และ Failures

ตรวจอ่านครบ 53 ข้อ: basics.ts 27 ข้อ (รวมโจทย์ภาพยาน 2 ข้อ) และ failures.ts 26 ข้อ เปรียบเทียบ prompt, options, misconception feedback, explanation ทุกข้อความ EN/RU/TH ที่ประกาศในสองไฟล์ ณ 29 กันยายน 2026 โดยใช้แนวทาง russian-thai-translate; เป็นการอ่านเนื้อหาและเฉลย ไม่ใช่การรับรองคุณภาพข้อสอบเชิงสถิติหรือการตอบข้อสอบผ่านเบราว์เซอร์ใหม่ 53 ครั้ง ผู้ตรวจนี้ไม่แก้ source; ส่งรายการแก้ให้ผู้รับผิดชอบ editorial แล้ว

พบข้อผิดพลาดชัดเจน:

- **b-leo-speed — ภาษาไทย:** แปล first cosmic velocity 7.9 km/s เป็น «ความเร็วหลุดพ้นแรก» ซึ่งสับสนกับ escape velocity 11.2 km/s ควรเป็น «ความเร็ววงโคจรวงกลมใกล้ผิวโลก (ความเร็วจักรวาลที่หนึ่ง)» ค่าและเฉลยตัวเลือกเดิมถูกต้อง คำอธิบาย b-escape ในไฟล์เดียวกันแยกสองค่านี้ถูกอยู่แล้ว
- **f-order-ms10 — ภาษาไทย:** «เส้นทางขีปนะ» พิมพ์ผิด ควรเป็น «เส้นทางขีปนวิถี»
- **f-proton2013 — ทั้งสามภาษา:** «every correction doubled the error / каждая коррекция удваивала ошибку / ทุกการแก้ทำให้ความคลาดเพิ่มเป็นสองเท่า» ระบุอัตราเพิ่ม ×2 อย่างไม่มีแบบจำลองหรือเงื่อนไขรองรับ สิ่งที่คำอธิบายต้องการสื่อคือการป้อนกลับผิดเครื่องหมายยิ่งเพิ่มความคลาดเคลื่อน ควรใช้ amplified / усиливала / เพิ่ม แทนจำนวนสองเท่า โดยไม่เปลี่ยนสาเหตุหรือเฉลย

ไม่พบข้อผิดพลาดของ answer key, ลำดับเฉลย หรือสูตรเกณฑ์คะแนนจากการอ่าน 53 ข้อนี้ สูตร gravity inverse square, independent two-out-of-three voting และ independent series reliability สอดคล้องโจทย์และหน่วย

ข้อสังเกตเพื่อบรรณาธิการรอบต่อไป ไม่จัดเป็นบั๊กเฉลยหรือเงื่อนไขหยุดงาน:

- บางข้อความใช้ «ขั้น» แทน «ท่อน» และ «น้ำหนักบรรทุก» แทน «มวลบรรทุก» ไม่สม่ำเสมอ เป็นงานศัพท์/สำนวน
- f-fts อธิบาย FTS ด้วยการทำลายยานเป็นหลัก ซึ่งตรงตัวอย่างจำลอง แต่คำทั่วไปครอบคลุมการยุติแรงขับได้ด้วย ดู [NASA range safety](https://nodis3.gsfc.nasa.gov/displayCA.cfm?Internal_ID=N_PR_8715_005A_&page_name=Chapter3) ควรระบุขอบเขตตัวอย่างเมื่อตีพิมพ์เป็นตำราทั่วไป
- ไม่เปิดประเด็น «simultaneous» ของ Ariane501 เป็นข้อผิดพลาดที่ต้องแก้ เพราะ [ESA สรุป Inquiry Board](https://www.esa.int/Newsroom/Press_Releases/Ariane_501_-_Presentation_of_Inquiry_Board_report) เองใช้คำสรุปนี้ และประเด็นบทเรียนคือความล้มเหลวจากซอฟต์แวร์ร่วมกัน

การอ่านครบไม่ได้หมายถึงตรวจแหล่งปฐมภูมิอิสระทุกวันเวลา/ความสูงทางประวัติศาสตร์ หรือเห็นภาพประกอบทุก variant ใหม่ การตรวจภาพและ browser journey เป็นหลักฐานคนละชุด
