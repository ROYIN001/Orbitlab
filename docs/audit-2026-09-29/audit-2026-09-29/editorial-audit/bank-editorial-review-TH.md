## การแก้ที่ยืนยันได้

แก้ **29 strings ใน 8 question IDs และ 5 source files** โดยไม่เปลี่ยนเฉลย สูตร numeric ค่าพารามิเตอร์ ลำดับคำตอบ น้ำหนัก หรือ ID รายละเอียดก่อน–หลังทุก string อยู่ใน [รายการแก้](bank-text-corrections.json)

- **r-isp:** ระบุว่า Isp·g0 คืออัตราเร็วไอเสียสมมูลซึ่งรวมแรงขับจากความดัน ไม่ใช่อัตราเร็วไอเสียทางกายภาพเพียงอย่างเดียว สอดคล้องนิยาม thrust และ equivalent exhaust velocity ของ [NASA Glenn](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/specific-impulse/)
- **r-liftoff-accel:** คำอธิบาย a = F/m − g ต้องเป็นความเร่งจากแรงขับลบความเร่งโน้มถ่วง ไม่ใช่ลบน้ำหนักซึ่งมีหน่วยแรง สูตรและคำตอบเดิมคงอยู่ ดู [NASA thrust-to-weight](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/thrust-to-weight-ratio/)
- **g-gyro-bias:** accelerometer วัด specific force และใช้แบบจำลองแรงโน้มถ่วงในการหา acceleration ไม่ได้วัด gravity โดยตรง เพิ่มขอบเขตการเติบโต t²/t³ ว่าเป็นการประมาณในช่วงสั้น ดูบท inertial navigation ใน [NASA technical report](https://ntrs.nasa.gov/api/citations/19780020137/downloads/19780020137.pdf)
- **g-gnss-alone:** จำกัดคำถามไว้ที่ single-antenna position aiding ตามระบบที่จำลอง อธิบายว่า GNSS หลายเสาอากาศหา attitude ได้ในระบบอื่น จึงไม่เหมารวมว่า GNSS ทุกแบบวัด attitude ไม่ได้ ดู [NASA small-spacecraft GNC](https://www.nasa.gov/smallsat-institute/sst-soa/guidance-navigation-and-control/)
- **c-rcs:** จำกัดโจทย์ให้เป็นท่อนจรวดที่ใช้ main-engine gimbal กับ RCS เท่านั้น และเครื่องยนต์เดี่ยวอยู่บนแกนกลาง การมี reaction wheels ในยานอื่นจึงไม่กลายเป็นตัวอย่างค้านเฉลย ดู [ESA control systems](https://www.esa.int/Enabling_Support/Space_Engineering_Technology/About_Control_Systems)
- **b-leo-speed:** ภาษาไทยแปล first cosmic velocity เป็นความเร็วหลุดพ้นผิด แก้เป็นความเร็ววงโคจรวงกลมใกล้ผิวโลกหรือความเร็วจักรวาลที่หนึ่ง โดยคง 7.9 km/s แยกจาก escape velocity 11.2 km/s ตามสูตร v_c = √(μ/r) และ v_esc = √(2μ/r) ในเนื้อหาเดิม
- **f-order-ms10:** แก้คำพิมพ์ผิด “เส้นทางขีปนะ” เป็น “เส้นทางขีปนวิถี”
- **f-proton2013:** เปลี่ยนข้ออ้างว่าทุกการแก้เพิ่ม error เป็นสองเท่า เป็นการเพิ่ม error จาก feedback ผิดเครื่องหมาย เพราะเนื้อหาไม่ได้กำหนด gain หรือช่วงเวลาที่ทำให้ได้ ×2 และระบุหน่วย yaw-rate ที่เกี่ยวข้องแทนการเหมารวมเซนเซอร์ทุกหน่วย

การสกัดก่อน–หลังยืนยันจำนวนและลำดับ 157 IDs, answer metadata และทุก localized path ตรงกัน ผลตรวจ AST สำหรับรอบข้อความถึง commit `76534dc1` อยู่ใน [text-only verification](text-only-verification.json) ไม่ได้ใช้หลักฐานนี้อ้างว่า rendering/layout follow-up ที่เกิดภายหลังไม่มีการเปลี่ยน AST ซึ่งเป็นหลักฐานแยกจากการอ่านเชิงความหมาย และผล focused/build รอบสุดท้ายให้ดูรายงานตรวจรับหลัก

## สิ่งที่คงเป็นข้อเสนอ

ศัพท์บางคำยังใช้ไม่สม่ำเสมอ เช่น ขั้น/ท่อน ลูป/วงควบคุม และน้ำหนักบรรทุก/มวลบรรทุก การปรับสำนวนทั้งคลังเป็นงานบรรณาธิการต่อ ไม่แก้แบบเหมารวมในรอบนี้ ข้อความ r-mass-ratio ที่ใช้เกณฑ์ประมาณมากกว่า 10 และคำอธิบาย FTS ที่เน้นการทำลายยานควรเพิ่มขอบเขตเมื่อนำไปใช้เป็นตำราทั่วไป การแก้ข้ออ้างเชิงปริมาณเพิ่มต้องมีแหล่งอ้างอิงและเงื่อนไขเฉพาะ จึงไม่เปลี่ยน key หรือสูตรด้วยการเดา จากการอ่านรอบนี้ไม่พบ key/rubric เพิ่มที่ยืนยันว่าผิด การเปลี่ยน policy เปิดเฉลย การเปลี่ยน rubric ให้ตรวจสิ่งที่โจทย์ปัจจุบันยังไม่ได้ตรวจ การปรับความยาก และการใช้สถิติ item discrimination/reliability ยังไม่ได้ทำ

การอ่านครั้งนี้ปิดช่องว่างเดิมที่ยังไม่ได้เปรียบเทียบทุกข้อความ TH/RU ใน **คลัง 157 ข้อที่ระบุ** แต่ไม่ใช่การรับรองจากบรรณาธิการมนุษย์อิสระ การตรวจแหล่งปฐมภูมิใหม่ของทุกวันที่และทุกค่าประวัติศาสตร์ หรือการรับรองคุณภาพข้อสอบเชิงสถิติ ไม่ใช่การตอบ 157 ข้อผ่าน UI และผล QA ไม่ใช่คะแนนเจ้าของเว็บ ส่วนบทเรียน 24 บทและข้อความกรณีศึกษาอ่านแยกในรายงานที่เกี่ยวข้อง ไม่ขยายข้ออ้างไปยัง i18n ทุกเมนูของผลิตภัณฑ์
