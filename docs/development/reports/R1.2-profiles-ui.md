# R1.2 — Learner profile and reset UI

Date: 2026-10-03. Plan: `Orbitlab-Development-Plan-TH.md`, R1.2; depends on R1.1 storage. This report records implementation work on the current candidate, not a claim that it has been merged or deployed. The integration report records the PR, merge and final checks.

## Implemented

- Native profile dialog reachable from the application shell and from lessons. Create, rename, switch and delete use stable profile IDs supplied by the repository; names are display labels, not authentication.
- Current learner context appears on the lesson catalogue and lesson-page header, including placement-test and result pages. A rename event refreshes these views. Result exports freeze learner name, history and catalogue before awaiting the assessment module or checksum.
- Explicit switch/create confirmation explains document reload, saved ownership, closing live flight/test screens, resumable saved tests and absence of live-flight restoration.
- Granular reset: learning only, tests including unfinished tests, both, or one recorded lesson. Confirmation identifies the learner and displays affected lesson/test counts, explains clearing attempts/grades/hints/revealed answers, preserves personal teaching content/designs/mission/notebook and offers a backup.
- Profile deletion identifies all owned work and personal settings/audio. It offers a backup and displays stored-record counts. Active and last-profile deletion require an explicit learner choice; the UI does not silently choose another person.
- Backup screen: current-profile or all-profile workspace JSON export, validated JSON import preview, create-new default, Keep Existing default for existing destinations, explicit Replace warning and backup action. Multi-profile restore creates new identities. Legacy project files are identified as limited to their recorded sections.
- JSON audio exclusion is visible, including destructive profile deletion. Uploaded audio uses separate binary export/import controls with validated source/count preview, current learner target, Keep Existing default and explicit Replace choice. Deletion also offers a separate audio backup before removing that learner.
- Invalid or unsupported primary import data is disclosed as preserved recovery data that will not be activated, using repository-provided quarantine/recovery counts.
- English, Thai and Russian feature translations, narrow-screen wrapping, native modal cancellation/focus restoration, and storage/locked/temporary/recovery failure messages.
- Async modal redraw now keeps focus inside the dialog; otherwise Escape after rename could reach the lesson route handler and navigate underneath the still-open dialog.
- Read-only and visit-only work can export the current readable workspace JSON. This recovery path does not enable profile mutations, reset, imports or durable media writes.
- Failed learning, instructor-draft and worksheet saves remain pending; profile transitions retry them strictly and keep the old learner open if persistence still fails. Mere rendering, language changes and backup/switch flushes do not replace untouched unreadable or newer stored data with fallback forms. Author edits track the flight draft, design draft and kind chooser separately.

## Interfaces and ownership

- UI: `src/ui/profiles/profile-dialog.ts`, `profiles.css`, `text.ts`; lightweight learner-context translations/styles stay available before the dialog is loaded.
- Lessons: `src/ui/lessons/lesson-mode.ts`; optional `profileName`, `manageProfiles`, `resetLearning` hooks; `recordedLessons()` supplies localized saved-history choices.
- Pending-save boundaries: `src/ui/lessons/profile-progress.ts`, `author-view.ts` and `worksheet-view.ts`.
- Root integration: `src/ui/profiles/app-profiles.ts`, application bootstrap and shell controls. This UI package does not directly rebind storage or resume a physics state.
- Repository contract: callbacks flush the old workspace, validate mutations, seal old ownership and reconstruct the document. A failed mutation remains visible in the dialog.
- New verification: `tests/profiles-i18n.test.ts`, `learner-profile-flush.test.ts`, `instructor-profile-flush.test.ts`, `tests/browser/journeys/learner-profiles.mjs`, `tests/browser/journeys/profile-session-safety.mjs`.
