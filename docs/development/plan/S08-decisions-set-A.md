**วิธีส่งและตอบ (ใช้กับทุกชุด)**
1. **แผ่นตอบหนึ่งหน้าต่อชุด:** ตารางแต่ละชุดด้านล่างคือแผ่นตอบที่ I ส่งให้เจ้าของ ทุกแถวกรอก "ข้อเสนอที่กรอกไว้" จาก §08.2–§08.4 แล้ว เจ้าของอ่านทางเลือกเต็มเฉพาะแถวที่อยากเปลี่ยน แถวที่ข้อเสนอคือ "เจ้าของเลือก" กรอกทางที่เอนไว้ และแถวที่ข้อเสนอคือเลื่อนหรือรอหลักฐานจะบันทึกเป็น "เลื่อน" พร้อมเงื่อนไข
2. **รูปแบบคำตอบ:** `A-1: ตามข้อเสนอ` หรือ `A-1: ตามข้อเสนอ ยกเว้น D-x (ทาง …), D-y (…)` ทำให้**ทุกแถวอื่นในแผ่นนั้นเป็น "ตัดสินแล้ว"** ตามข้อเสนอที่กรอกไว้ I คัดลอกคำตอบของเจ้าของตรงตัวพร้อมวันที่ลงในทุกแถว แถวที่ยกเว้นและระบุทางบันทึกตามทางนั้น แถวที่ยกเว้นแต่ไม่ระบุทางยังเป็น "เปิด" สำหรับแถวแบบยืนยัน (D-8, D-33, D-34, D-36.A1–A5 และ G3 ในแผ่น A-1) "ตามข้อเสนอ" คือยืนยันพฤติกรรมหรือการส่งมอบที่เกิดไปแล้ว คำตอบ `A: …` ใช้กับแผ่น A-1 และ A-2 ที่ส่งไปแล้วทั้งคู่ คำตอบที่ไม่ระบุชื่อแผ่นไม่นับเป็นคำตอบของแผ่น
