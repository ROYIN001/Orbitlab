> คู่กับแผนแม่บท v2.0 (ร่าง) · วันที่ 2026-10-04 · โค้ดล่าสุด (main) `5f9aa2e` / เว็บที่ใช้งานอยู่ `09cc2f5` · ทุกขั้นเริ่มได้เมื่อเจ้าของอนุญาตเท่านั้น · คำศัพท์และตัวย่อดูท้ายเอกสาร (§8)

**ผลเหมือนเดิม** (หลักข้อแรกของเจ้าของ) หมายถึง แอปหน้าตาเหมือนเดิมและคำนวณได้ผลเดิมทุกตัวเลข เพียงแต่เร็วขึ้นหรือเบาลง งานแบบนี้ทำก่อน และพิสูจน์ด้วยการวัดก่อนและหลัง

## 1. ตอนนี้อยู่ตรงไหน

- **R1 เสร็จและขึ้นเว็บแล้ว** ประตู G1 ผ่าน
- **R2 ขึ้นเว็บแล้ว แต่ G2 (ประตูรับ R2) ยังไม่ลงนาม** รอเจ้าของตัดสินการจัดหน้าจอ Launch (D-36) งานที่เหลือ: ชุดแก้ 11 PR, การทดสอบ R2 ในทุก PR, จัดแผงเอง, ฐานการเข้าถึง, ปุ่มกระโดดไปเหตุการณ์
- **บั๊ก P0 ที่ผู้ใช้เจอ 1 ตัว (LUI-01):** กด "Use for the next launch" ขณะหยุดบิน แล้วเที่ยวบินและการบันทึกหาย จะแก้เป็นงานแรก ส่วน P0 ที่ยังเปิดทั้งหมด 9 รายการอยู่ใน K0 ทั้งหมด (งานบันทึกสถานะ งบขนาด หลักฐานฟิสิกส์ ชื่อสถาบัน G2 ฯลฯ)
- **R3 ส่งมอบครบ** (เจ้าของประกาศ 2026-10-04) งานเสริมที่ยังเปิดย้ายไป "R3+ ต่อยอด" ไม่มีข้อใดถูกทิ้ง
- **ความเสี่ยงที่ยังเปิด:**
  - การขึ้นเว็บเคยล้ม 2 ครั้งโดยไม่รู้สาเหตุ
  - พื้นที่เหลือของไฟล์ออฟไลน์ 280.3 kB (วัดบนข้อมูลใน repo; บนเว็บจริงน้อยกว่านี้และยังไม่ได้วัด)
  - หลักฐานฟิสิกส์ชุดเต็มขาดช่วง
  - ยังไม่เคยทดสอบกับผู้ใช้จริง
- **ยังไม่มีงานใดได้รับอนุญาต**

## 3. รายละเอียดทีละขั้น

ทุกคลื่นจบด้วย "ประตู" (จุดตรวจท้ายคลื่น) ที่เจ้าของต้องอนุมัติก่อนเริ่มคลื่นถัดไป ไม่มีคลื่นใดเดินต่อเองอัตโนมัติ

### Day 0 — ตรวจข้อเท็จจริง
- **ช่วงเวลา:** วันที่เจ้าของอนุมัติแผน ก่อน Day 1 (ไม่แก้ repo ไม่เปิด PR)
- **เป้าหมาย:** ยืนยันว่า GitHub ยังตรงกับแผน
- **จะทำอะไร:** ยืนยันรหัสรุ่นโค้ด (SHA) และผลการขึ้นเว็บ · สั่งเครื่องรันทดสอบฟิสิกส์เต็มชุด (ผลความเร็ววัดไว้แล้ว)
- **ผู้ใช้เห็นอะไร:** ไม่มี
- **ต้องผ่านอะไร:** ส่วนต่างที่พบบันทึกเป็นแถววางแผนใหม่ (re-plan) ก่อน Day 1
- **เจ้าของ:**
  - *วันนี้:* ตอบกติกางบขนาดชั่วคราวได้ทันที (D-38) · อนุญาตให้เครื่องรันทดสอบ · อนุญาต K0 (D-65)
- **อ้างอิงในแผนหลัก:** S05 §05.0

### K0 — ปิดงาน R2 (5–9 ต.ค. 2026, Day 1–5)
- **เป้าหมาย:** แก้บั๊ก P0 ลงนาม G2 ให้เว็บที่ขึ้นตรงกับโค้ดที่ตรวจแล้ว มีหลักฐานฐานไว้เทียบ
- **ส่วนที่พัฒนา:**
  - *Launch:* แก้บั๊กเที่ยวบินหาย · ภาพหน้าจอให้ลงนาม G2 · ทดสอบ R2 ในทุก PR
  - *ฟิสิกส์:* รันหลักฐานเต็มชุด ถ้าแดงต้องหาสาเหตุ ห้ามบันทึกทับ
  - *ความเร็ว:* เริ่มเครื่องมือพิสูจน์ "ผลเหมือนเดิม" และด่านวัดความเร็ว
  - *การปล่อยรุ่น:* แยกเพดานขนาดโค้ดกับข้อมูล · บันทึกสถานะให้ตรง GitHub · รับแผนเข้า repo
  - *บทเรียนและครู:* ชื่อสถาบันในแพ็ก · เตรียมการศึกษาผู้ใช้รอบ 1
- **ผู้ใช้เห็นอะไร:** บั๊ก P0 หายไป ที่เหลือเป็นงานเบื้องหลัง
- **ต้องผ่านอะไร (GCO = ประตูปิดงานค้าง, GK0 = ประตูท้าย K0):**
  - ผล Day 0 บันทึกแล้ว
  - บั๊ก P0 แก้แล้ว · G2 ลงนาม
  - เว็บที่ขึ้นตรงกับโค้ดที่ตรวจแล้ว · สถานะตรง GitHub
  - ทดสอบ R2 อยู่ในทุก PR และพิสูจน์ว่าจับบั๊กได้
  - ชื่อสถาบันแก้ตาม D-42
  - มีผลฟิสิกส์ (หรือมีงานหาสาเหตุ)
  - เจ้าของรับแผน v2.0 ส่วน K0–K1 (CO-8)
- **เจ้าของ (ชุด A ~1–2 ชม. + ภาพ G2 ~1 ชม.):**
  - *วันที่ 1:* อนุญาต K0 และบันทึกการปิด R3 (D-65), บั๊กข้อมูลหายมาก่อน (D-63), งบขนาด (D-38), ชื่อสถาบัน (D-42), ปิด G0 (D-59), ยืนยัน R1/R2 (D-33, D-34), รับทราบ (D-12)

### K1 — ข้อมูลปลอดภัย (12–23 ต.ค., Day 6–15)
- **เป้าหมาย:** งานผู้เรียนไม่หายเงียบ ไม่มีผลเท็จ และเริ่มงานเร็วชุดแรก
- **ส่วนที่พัฒนา:**
  - *ความปลอดภัยข้อมูล:* ตัวกันสองแท็บ (lock) ค้าง · งานไม่ถูกบันทึก · โปรไฟล์ว่าง · ไฟล์รุ่นใหม่กว่าถูกเขียนทับ · กู้ภาพเมื่อ WebGL หลุด
  - *Build:* rating ที่คำนวณไม่จบไม่ถูกเก็บ · แบบไม่ถูกแทนที่โดยไม่ถาม
  - *บทเรียนและครู:* ช่องที่พิมพ์ไม่หาย · บทเรียนถูกต้อง · ร่างคำแถลงความเป็นส่วนตัวและคู่มือไทย (ถึง K3)
  - *Orbit / Launch:* ตัวเลขตรงวงโคจรบนจอ · ตัวเลขวิเคราะห์และ CSV ถูกต้อง (ถึง K2)
  - *ความเร็ว:* ติดตั้งครั้งแรกไม่ดาวน์โหลดซ้ำ (9,438.5 kB) · ลดการค้างตอนเริ่มและตอนจรวดยกตัว (ถึง K2) · อัปเดตแอปออฟไลน์ง่ายขึ้น
  - *ฟิสิกส์:* วิจัยแหล่งข้อมูลยาน ไม่มีโค้ด (ถึง K3)
  - *ภาษาไทย:* ศัพท์ไทยที่ตัดสินแล้วและอภิธานศัพท์กลาง
- **ผู้ใช้เห็นอะไร:** ส่วนใหญ่เป็นงานความปลอดภัยที่มองไม่เห็น ผู้ใช้รู้สึกว่า "ไม่มีอะไรหาย" และติดตั้งเร็วขึ้น
- **ต้องผ่านอะไร (GK1 = ประตูท้าย K1, ปิด G0, G1+ = ตรวจเพิ่มของระบบบันทึก):**
  - บั๊กทำงานหาย/ผลเท็จชุด K1 แก้ครบ (KPI-14 = 0)
  - ทดสอบสองแท็บ พื้นที่เต็ม โปรไฟล์เสีย ไฟล์รุ่นใหม่กว่า ผ่าน · ข้อมูลที่เก็บเท่าเดิมทุกไบต์
  - ปิด G0: ตาราง ADR ครบ ทดลองแผนที่เลือกเทสต์แล้ว และบันทึกผลอ้างอิง (oracle) บนฐานที่ตรึง
  - คำนวณความเร็วงานใหม่จากที่วัดได้
- **เจ้าของ (ชุด B ~1–2 ชม.):**
  - *ก่อนผู้ใช้คนแรก:* ใช้คะแนนเพื่อฝึก ไม่ใช่ตัดเกรด (D-49), ช่องรายงานปัญหา (D-60), อนุมัติคำแถลงความเป็นส่วนตัว
  - *ก่อนเริ่มงานที่เกี่ยวข้อง (ต้น K1):* CSV (D-45), rating ที่คำนวณไม่จบ (D-67), ย้ายไฟล์เพลงที่ชื่อชนกัน (D-68), Data Saver (D-69)
  - *ภายใน GK1:* เบราว์เซอร์ (D-40), อุปกรณ์ (D-56), ลดคุณภาพต้องประกาศ (D-43), เครื่องตรวจการเข้าถึง axe-core (D-44) ตามกติกาเพิ่มเครื่องมือพัฒนาทีละตัว (D-17), รูปแบบเวลา (D-46), ประตูผู้ใช้ (D-54), ใช้ผลทดสอบซ้ำ (D-64), หน้า Engineer (D-21), ไฟล์รุ่นใหม่ (D-22)
  - *ภายใน Day 35:* สาย Node (D-3/D-4)
  - *งานคน:* หาผู้ทดลอง
  - *ท้ายคลื่น:* อนุมัติ GK1 และอนุญาตคลื่นถัดไป (D-65) ~0.5–1 ชม.

### K2 — R2 ครบและเร็วขึ้น (26 ต.ค.–20 พ.ย., Day 16–35)
- **เป้าหมาย:** R2 ครบตามนิยาม และลดงานซ้ำชุดหลักโดยผลไม่เปลี่ยน
- **ส่วนที่พัฒนา:**
  - *Launch:* แถบคำสั่งกะทัดรัด จอเตี้ย · บอกเหตุเมื่อเร่งเวลาไม่ถึง · ภาพช่วงร่อนไม่กระโดด · ปุ่มไปจุดแรงดันอากาศสูงสุด (Max-Q)/แยกขั้น · จัดแผงเอง (ถึง K3)
  - *ภาษาไทยและการเข้าถึง:* สระ/วรรณยุกต์ไม่ถูกตัด · ความต่างสีตัวอักษร (contrast) · ปุ่ม ≥44 px
  - *ความเร็ว:* Orbit ที่หยุดไม่วาดซ้ำ · เครื่องมือ Orbit ไม่ค้าง · โหลดเฉพาะภาษาที่ใช้ · ฟิสิกส์ตัดงานซ้ำแบบผลเท่าเดิมทุกบิต
  - *ความปลอดภัยข้อมูล:* งานที่ยกเลิกไม่แสดงเป็นผลสมบูรณ์ · จำกัดขนาดไฟล์นำเข้า

## 8. คำศัพท์และตัวย่อ

**งานโค้ดและการปล่อยรุ่น**
- **PR** — ชุดแก้โค้ดหนึ่งชิ้นที่เสนอเข้า GitHub ให้ตรวจก่อนรวม · **merge** — รวม PR เข้าโค้ดหลัก · **repo** — ที่เก็บโค้ดบน GitHub
- **SHA** — รหัสประจำรุ่นของโค้ด (เช่น `5f9aa2e`) · **tag** — ป้ายชื่อรุ่นที่ติดกับโค้ดรุ่นหนึ่ง · **v1.0** — รุ่นเสถียรแรกที่ติด tag ให้โรงเรียนใช้
- **refactor** — จัดโครงสร้างโค้ดใหม่โดยผลไม่เปลี่ยน · **worker** — ส่วนที่คำนวณเบื้องหลังแยกจากหน้าจอ · **editor** — ตัวแก้แบบใน Build
- **Node 22** — รุ่นของเครื่องมือที่ใช้สร้างเว็บ หมดการดูแล 2027-04-30 จึงต้องย้ายรุ่น
- **ไฟล์ออฟไลน์ (precache)** — ไฟล์ที่แอปดาวน์โหลดเก็บไว้ให้ใช้ได้โดยไม่มีเน็ต
- **CSV** — ไฟล์ตารางที่ส่งออกได้ · **Data Saver** — โหมดประหยัดข้อมูลของเบราว์เซอร์

**การตรวจและการวัด**
- **P0** — ความรุนแรงสูงสุด (P0 > P1 > P2 > P3)
- **ประตู (gate)** — จุดตรวจที่ต้องผ่านรายการตรวจและเจ้าของอนุมัติก่อนไปต่อ
- **GCO** — ประตูปิดงานค้าง (ท้าย K0) · **GK0–GK6** — ประตูท้ายคลื่น K0–K6 · **G0** — ประตูหลักฐานตั้งต้น · **G1+** — ตรวจเพิ่มของระบบบันทึกข้อมูล · **G2** — ประตูรับ R2 (ลงนามหน้าจอ Launch) · **G4-S** — ผ่านการตรวจชุด Soyuz ก่อนเริ่ม ISS · **G4** — ความสมจริงทั้งกองยาน · **G5** — ISS · **G6** — ห้องนักบิน · **G8** — ดวงจันทร์
- **คลื่น (K0–K6)** — ช่วงงานแต่ละช่วงในแผน · **re-plan** — แถวบันทึกส่วนต่างและการวางแผนใหม่
- **ผลเหมือนเดิม (identical-output)** — หน้าตาและตัวเลขเหมือนเดิมทุกอย่าง แค่เร็วหรือเบาลง
- **oracle** — ผลอ้างอิงที่บันทึกไว้ก่อนแก้ เพื่อเทียบว่าผลไม่เปลี่ยน · **`--compare`** — โหมดของสคริปต์วัดที่เทียบก่อนกับหลัง
- **KPI-xx** — ตัวชี้วัดในแผน (S04) · **ADR** — บันทึกการตัดสินใจด้านสถาปัตยกรรม
- **pilot** — ทดลองใช้จริงที่สถาบันหนึ่งแห่ง · **contrast** — ความต่างสีตัวอักษรกับพื้นหลัง

**ฟิสิกส์และภารกิจ**
- **WebGL context** — ช่องวาดภาพ 3 มิติของเบราว์เซอร์ ซึ่งมีจำนวนจำกัด · **lock** — ตัวกันไม่ให้สองแท็บเขียนข้อมูลพร้อมกัน
- **rating** — ตัวเลขสมรรถนะของแบบจรวดที่ Build คำนวณ
- **liftoff** — ขณะจรวดยกตัว · **Max-Q** — จุดแรงดันอากาศสูงสุด · **fairing** — ฝาครอบส่วนบรรทุก
- **J2** — ผลของโลกที่ป่องตรงเส้นศูนย์สูตรต่อวงโคจร · **Lambert / SSO / re-entry** — เครื่องมือวางแผนย้ายวงโคจร / วงโคจรสัมพันธ์ดวงอาทิตย์ / การกลับเข้าบรรยากาศ
- **epoch** — ช่วงเวลาอ้างอิงที่ตรึงไว้ · **hard dock** — ขั้นเชื่อมแน่นหลังจับยึด · **Horizons** — บริการข้อมูลตำแหน่งดาวของ NASA JPL

**ชื่อสายงาน**
- **R1…R8** — ระยะพัฒนาหลัก · **R3+** — งานต่อยอดของ R3 · **ED** — การสอน ภาษาไทย สถาบัน · **HU** — งานกับผู้ใช้จริง · **R7** — ปล่อยรุ่นและคุณภาพ · **DEC** — คำถามถึงเจ้าของ
- **D-xx** — เลขคำถาม/การตัดสินใจในทะเบียน (S08) · **M-xxx** — เลขรายการงานในแผน · **CO, FX, EQ ฯลฯ** — รหัสชุดงานในบรรทัดอ้างอิง
